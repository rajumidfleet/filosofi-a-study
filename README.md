# Filosofi A – Studieatlas

Interaktiv, statisk studiesajt för **Filosofins historia** i Filosofi A.

## Funktioner

- meny för föreläsning 1–12
- pedagogisk berättelse före detaljerna
- filosofer och kärnbegrepp grupperade per problem
- jämförelser av centrala motsättningar
- flashcards och snabbtest
- lokal klarmarkering/progress i webbläsaren
- responsiv layout för mobil och dator

## GitHub Pages

Sajten är byggd utan ramverk och kan köras direkt från repository-roten.

Aktivera under:

**Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**

Därefter blir adressen normalt:

`https://rajumidfleet.github.io/filosofi-a-study/`

## Struktur

- `index.html` – appens skal
- `styles.css` – design och responsiv layout
- `app.js` – föreläsningsinnehåll, navigation, quiz och progress

Innehållet är organiserat från kursens föreläsnings-PDF:er och kan byggas ut successivt med fler detaljer, originaltexter och examinationsfokus.
