# Begreppsindex – 2026-09-30

113 förklaringar: alla 112 befintliga kursanknutna poster samt en kompletterande axiomförklaring med egna källor (MathWorld och SEP). Samma begrepp behålls separat när betydelsen skiljer sig mellan kursavsnitt, exempelvis Logos. Inga kurs-PDF:er publiceras.

Kontrollerat:
- Global sökning: ”vad är ett axiom?” ger definition direkt; Enter öppnar indexets axiomkort.
- Sökfältets fokus behålls vid filtrering; kursfilter och sökning bevaras vid omladdning genom URL-parametrar.
- Logos ger två sammanhang och ett efter kursfilter. Okända ord ger ett uttryckligt tomt resultat.
- Länk från axiom öppnar Logik: giltighet och sundhet; Aristoteles länkas som relaterat område.
- Mobil 390×844 utan horisontell overflow, samt visuell desktopkontroll.
- 16 tester inklusive frågor, alias, svensk Unicode, alfabetisk ordning och kombinerade filter. Begreppssökningens hjälpmodul når 100 % linje-/gren-/funktionstäckning.
- Oberoende kodgranskning: inga handlingskrävande fynd. npm audit och gitleaks rena.

Sökningen är lokal textmatchning med stöd för några vanliga frågeord och explicita alias. Den är inte en allmän frågesvarstjänst och indexet täcker ett urval, inte alla filosofiska termer.
